# jabu

Статическая merge-головоломка по `frog-merge-mechanics.md`. HTML, CSS, JavaScript, без зависимостей и сервера приложения.

## Запуск

```sh
npm run dev
```

Открыть http://localhost:5183. Нужны Python 3 и браузер с поддержкой ES modules. Проверка правил: `npm test` (Node.js 18+).

## GitHub Pages

1. Загрузить содержимое этой папки в GitHub-репозиторий, включая `frogs/`.
2. В Settings → Pages выбрать Deploy from a branch, ветку `main` и папку `/ (root)`.
3. После публикации открыть адрес, указанный GitHub Pages.

Сборка не требуется. Все пути относительные: приложение работает и по адресу `username.github.io/repository/`.

## Управление

Перетащить жабу на любую жабу того же уровня либо нажать на двух жаб по очереди. Клавиатура: Tab для выбора клетки, Enter/Space для нажатия. На телефоне поле поддерживает перетаскивание, страница прокручивается за его пределами.

Звук включается после первого пользовательского жеста. Квак воспроизводится из `frog-croak.mp3` через Web Audio API: каждый следующий полученный уровень звучит ниже и дольше за счёт уменьшения скорости воспроизведения. Уровень 2 использует исходную скорость. Кнопка вверху выключает звук. Включите `frog-croak.mp3` при публикации. При ошибке загрузки используется синтезированный квак; внешние сервисы не нужны.

Арты `frogs/1.png`–`13.png` соответствуют уровням. На уровнях выше 13 используется последний арт с актуальным номером. Текущая партия и рекорд очков сохраняются в localStorage после каждого объединения и начала новой игры. Перезагрузка восстанавливает партию, новая игра сохраняет рекорд.

Баланс и начальная раскладка — в `game.js`, оформление — `style.css`, звук — `audio.js`, управление — `app.js`.
