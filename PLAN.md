# План реализации Frog Merge

- [x] Изучить `frog-merge-mechanics.md` и использовать ранги изображений из `frogs/`.
- [x] Агент logic (low): чистая игровая модель, генерация 85/15, очки, конец партии и тесты.
- [x] Агент audio (low): синтез квака, возрастающая длительность и понижающаяся частота по уровню, выключатель звука.
- [x] Агент style (low): адаптивное оформление, состояния выбора, допустимых целей и анимации.
- [x] Основной агент: интеграция, pointer drag-and-drop, выбор двумя нажатиями и клавиатурой, сброс и окно результатов.
- [x] Подготовить относительные пути и инструкцию публикации на GitHub Pages без сборки.
- [x] Проверить правила автоматическими тестами и синтаксис модулей.
- [ ] Проверить визуальный вид, звук и сенсорное управление вручную в браузере.

Уровни выше 13 используют последний доступный арт с текущим номером; механика не ограничивает рост. Партия и рекорд очков сохраняются в localStorage.
